# Dokümantasyon

Bu dizin, proje geliştirme ve yardımcı dokümantasyon için ayrılmıştır:

- [setup-commands.sh](./setup-commands.sh): İlk scaffold döneminden kalma referans script. Güncel kurulum için kök README dosyasındaki komutlar kullanılmalıdır.
